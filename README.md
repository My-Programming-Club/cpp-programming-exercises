# C++ Programming Exercises

132 small C++ programs I wrote while following a Udemy C++ course. Each file is one exercise, and the number at the end of the file name follows the order of the course, so [`DemoFirstProgram23.cpp`](DemoFirstProgram23.cpp) comes early and [`AllAboutThrow227.cpp`](AllAboutThrow227.cpp) comes near the end.

## What the exercises cover

- **Language basics:** operators, conditions, `switch`, loops, `auto` and variadic functions, for example [`DemoLoops71.cpp`](DemoLoops71.cpp) and [`BitwiseOperators40.cpp`](BitwiseOperators40.cpp).
- **Number and pattern programs:** prime numbers, Armstrong numbers, factorials, factors, reversing a number and drawing patterns.
- **Arrays and strings:** linear and binary search, maximum elements, palindromes, counting vowels and words.
- **Functions:** overloading, default arguments and function templates.
- **Object-oriented programming:** classes, access specifiers, constructors and destructors, inheritance, polymorphism, virtual functions, abstract classes, friend functions and `final`.
- **Pointers and memory:** pointers, dynamic allocation, and base class pointers to derived objects.
- **Exceptions:** `try`, `throw` and `catch`.

## Compile and run an exercise

```sh
g++ -std=c++17 PrimeNumber78.cpp -o prime
./prime
```
